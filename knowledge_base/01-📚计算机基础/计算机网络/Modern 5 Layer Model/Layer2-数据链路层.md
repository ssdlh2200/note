# Layer2-数据链路层
## 数据链路层概念
1. 数据链路层主要作用
    - 封装成帧：将交付的协议数据单元，添加帧头和帧尾封装成帧
    - 差错检测：帧在传输过程中可能会出现误码，就是比特0变为1，或者比特1变为0。而差错检测就是发送方，在发送前基于待发送的数据和检错算法（循环冗余校验CRC），计算出检错码，并将其封装在帧尾。接收方收到后就可以判断是是否误码。
    - 可靠传输：如果数据链路层
        * 向上层提供的是不可靠服务，那么就会直接丢弃该帧
        * 如果向上层提供的可靠服务
            + 停止等待协议
            + 回退N帧协议
            + 选择重传协议
2. 数据链路层PDU（protocol data unit）
	- **帧（Frame）**
3. 数据链路层主要协议
	- 局域网（LAN）协议
	- 广域网（WAN）协议

##### 字节填充
![](https://cdn.nlark.com/yuque/0/2023/png/33704534/1687592909859-89d06f85-a32f-4173-a20b-43c4bf557713.png)

PPP使用0x7E（01111110)作为这个定界符，即路由器检测到某个字节为0x7E就说明上个帧传输结束，开始下个帧的传输。

当PPP使用异步传输时，我们使用0x7D（01111101）作为转义符，转义的规则如下：

+ 把信息字段中出现的每一个0x7E字节转变为2字节序列(0x7D，0x5E)。
+ 若信息字段中出现一个0x7D的字节(即出现了和转义字符一样的比特组合)，则把转义字符0x7D转变为2字节序列(0x7D，0x5D)。
+ 若信息字段中出现ASCII码的控制字符(即数值小于0x20的字符)，则在该字符前面要加入一个0x7D字节，同时将该字符的编码加以改变。例如，出现0x03(在控制字符中是“传输结束”ETX)就要把它转变为2字节序列的(0x7D，0x31)。

## 数据链路层的实际应用
### 二层以太网交换机
#### 工作原理
二层以太网交换机（Layer 2 switch）工作在局域网中
通过数据帧的目标MAC地址，将数据帧转发到目标主机
#### 三种工作模式
| **阶段**   | **目的**     | **关注的 MAC 地址**      | **后续通信**          |
| -------- | ---------- | ------------------- | ----------------- |
| **学习模式** | 构建 MAC 地址表 | **源 MAC 地址**        | 决定转发的依据。          |
| **泛洪模式** | 处理未知目标/广播  | **目标 MAC 地址**（如果未知） | 帮助交换机学习目标 MAC 地址。 |
| **转发模式** | 精确定位发送路径   | **目标 MAC 地址**（如果已知） | 实现高效的点对点通信。       |
#### 虚拟局域网Virtual Local Area Network
在交换机的泛洪模式中，当有多个主机和多个交换机互相连接时
- 一个广播包从第一个交换机的连接端口转入，从剩余端口转出
- 同理，在第二个交换机的连接端口转入，从剩余端口转出
- ....
- 此时形成的广播风暴，所以要划分虚拟局域网，让广播包在规定的广播域传播，避免这种情况

虚拟局域网之间的通信就会用到路由器或者使用三层交换机
#### 生成树协议(STP)
消除二层网络中的环路，后续用到可以了解了解......
