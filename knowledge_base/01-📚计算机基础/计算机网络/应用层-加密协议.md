### 证书
#### PKI、CSR、CA
- **PKI(Public Key Infrastructure，公钥基础设施)**
    - 管理证书、密钥、身份验证的完整体系
- **CSR(Certificate Signing Request，证书签名请求)**
    - 向 CA 申请证书时提交的“申请文件”
- **CA(Certificate Authority，证书颁发机构)**
    - 给证书签名、验证身份的机构

两种生成证书过程中的文件
- **CSR** = 公钥 + 证书信息 + 私钥签名用来申请证书
- **CRT** = 公钥 + 证书信息 + CA/私钥签名 最终的证书，用于服务器部署 

生成证书的流程如下：
```
私钥 -> CSR文件 -> CRT证书
```

#### 生成RSA密钥
在Linux中输入openssl version查看版本建议在 3 以上

#### 生成CSR文件 - 交互式
CSR文件包含：
- 主题信息
    - CN（Common Name）：域名，例如www.example.com
    - O（Organization）：组织名称
    - OU（Organization Unit）：部门名称
    - L（Locality）：城市
    - ST（State）：省
    - C（Country）：国家代码
- 公钥
    - 包含生成的公钥
- 签名
    - 使用私钥进行的签名
```plain
> openssl req -new -key private.pem -out cert.csr

> 输入参数：
CN
ShanXi
XIAN
SSDLH
SSDLH
example.com(网站的域名或者填ip 192.168.75.128)
ssdlh@qq.com
为CSR文件指定密钥(不指定也可以)
为公司指定别名(不指定也可以)
```

可视化查看并验证生成的CSR文件
```
> openssl req -in cert.csr -text -noout -verify
```
内容如下：
```txt
verify OK
Certificate Request:
    Data:
        Version: 1 (0x0)
        Subject: C = CN, ST = SHANXI, L = XIAN, O = no, OU = no, CN = ssdlh.com, emailAddress = 2544310147@qq.com
        Subject Public Key Info:
            Public Key Algorithm: rsaEncryption
                RSA Public-Key: (2048 bit)
...........
```

#### 生成CSR文件 - 通过配置文件
上述创建CSR文件需要交互式输入信息创建CSR文件，但可以通过脚本提前配置好这些信息，一键创建CSR文件
创建**cert.conf**文件
```txt
[ req ]
default_bits       = 2048
distinguished_name = req_distinguished_name
req_extensions     = req_ext
prompt             = no

[ req_distinguished_name ]
C  = CN
ST = SHANXI
L  = XIAN
O  = none
OU = none
CN = www.ssdlh.com
emailAddress = 2544310147@qq.com

[ req_ext ]
subjectAltName = @alt_names

[ alt_names ]
DNS.1 = www.ssdlh.com
DNS.2 = ssdlh.com
DNS.3 = *.ssdlh.com

```
- distinguished_name：csr文件配置块名称，例如\[ req_distinguished_name \]
- req_extensions：拓展配置块名称，例如\[ req_extensions \]
- subjectAltName：域名信息配置块名称，例如\[ alt_names \]
- prompt：禁止交互式创建
通过下面命令生成CSR文件
```java
> openssl req -new -key private.pem -out cert.csr -config cert.conf
```

#### 生成CRT文件
##### 通过CA机构签名生成CRT文件
- 创建好CSR文件后，发给CA机构就可以生成证书
##### 生成根证书CRT文件
根证书就是一个普通的crt文件，这里生成的是一个自签名根证书
```java

openssl req \
-x509 -newkey rsa:2048 \
-sha256 \
-days 365 \
-nodes \
-keyout rootCA-key.pem \
-subj "/C=CN/ST=SHANXI/L=XIAN/O=SSDLH_ROOTCA/OU=SSDLH_ROOTCA/CN=SSDLH_ROOTCA/emailAddress=2544310147@email.com" \
-out rootCA-cer.crt

C (Country Name): 				国家代码
ST (State or Province Name): 	省或州的全名
L (Locality Name): 				城市或区域的名称
O (Organization Name): 			组织的名称
OU (Organizational Unit Name): 	组织单元名称，通常是部门的名称
CN (Common Name): 				通用名称，通常是证书颁发者的名称或者证书用于的域名，
emailAddress: 					电子邮件地址
```
##### 使用根证书签名CSR文件
```java
openssl x509 \
-req \
-in cert.csr \
-CA rootCA-cer.crt \
-CAkey rootCA-key.pem \
-CAcreateserial \
-out cert.crt \
-days 365 \
-extensions req_ext \
-extfile cert.conf \
-sha256 
```
**注意：使用根证书签名给CSR文件签名时，必须包含extensdions和extfile，否则添加的域名不生效**
查看签名后的证书文件
```
> openssl x509 -in cert.crt -noout -text
```
查看域名是否添加成功
```
> openssl x509 -in cert.crt -noout -text | grep -A1 "Subject Alternative Name"
```
内容如下，说明添加成功
```
X509v3 Subject Alternative Name:
    DNS:ssdlh.com, DNS:*.ssdlh.com
```

#### 安装根证书和签名后的证书
1. 首先在操作系统host文件中将ip映射域名
    - 192.168.5.2 web.ssdlh.com
2. 打开windows的cert.mgr安装根证书
3. 将根证书签名的证书放到服务器中
4. 启动一个HTTPS服务器
```python
import http.server
import ssl
server_address = ('0.0.0.0', 443)
httpd = http.server.HTTPServer(server_address, http.server.SimpleHTTPRequestHandler)
httpd.socket = ssl.wrap_socket(httpd.socket,
                               server_side=True,
                               certfile='cert.crt',
                               keyfile='private.pem',
                               ssl_version=ssl.PROTOCOL_TLS)
print('run https...')
httpd.serve_forever()
```
5. 访问https://www.web.ssdlh.com验证证书是否受信任安装成功
6. 注意：新版的谷歌浏览器怎么都连接不上，可以使用chrome53，firefox，edge
