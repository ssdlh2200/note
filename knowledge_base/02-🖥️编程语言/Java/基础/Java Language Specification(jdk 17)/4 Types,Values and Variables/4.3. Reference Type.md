# 4.3. Reference Type
## Java中的引用类型
### 值传递辨析
#### 变量值传递
```java
static class Person{  
    public String name;  
}  
public static void main(String[] args) {  
    Person jack = new Person();  
    jack.name = "jack";  
    Person lisa = new Person();  
    lisa.name = "lisa";
    System.out.println(jack);  
    System.out.println(lisa);
    //==========================  
    jack = lisa; //在此处下断点 
    //==========================
    System.out.println(jack.name);  
    return;  
}
```
程序输出
```text
com.ssdlh.d9.ReferenceTypeTest$Person@685f4c2e
com.ssdlh.d9.ReferenceTypeTest$Person@7daf6ecc
```

#### 方法值传递
```java
static class Person{  
    public String name;  
}  
static void change(Person p){  
    Person lisa = new Person();  
    lisa.name = "lisa";  
    //===================  
    p = lisa; //此处下断点  
    //===================  
}  
public static void main(String[] args) {  
    Person jack = new Person();  
    jack.name = "jack";  
    change(jack);  
    System.out.println(jack.name);  
    return;  
}
```
