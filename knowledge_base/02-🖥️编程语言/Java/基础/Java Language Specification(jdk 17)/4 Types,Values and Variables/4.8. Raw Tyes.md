# 4.8. Raw Tyes
## 原始类型基本概念
- Raw Tyes是对一个泛型类型忽略类型参数后得到的类型。
- 也就是说对于一个泛型类型，在使用时不写类型参数，那就是raw type
```java
List<String> list;//参数化类型
List list;//原始类型
```

| 类型         | 是否 raw type | 原因                 |
| ---------- | ----------- | ------------------ |
| List       | ✔           | 是泛型类List\<E\>的擦除版本 |
| Map        | ✔           | 是泛型Map\<K,V\>的擦除版本 |
| String     | ❌           | 不是泛型类              |
| Object\[\] | ❌           | 数组元素不是 raw type    |
