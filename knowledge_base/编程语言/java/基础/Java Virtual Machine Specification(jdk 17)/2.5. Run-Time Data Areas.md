# 2.5. Run-Time Data Areas
### 2.5.2. Java Virtual Machine Stacks
#### Java虚拟机栈概念
每个Java虚拟机线程都有一个私有的Java虚拟机栈，**该栈在线程创建时被同时创建**。Java的虚拟机栈用于存储栈帧（stack frame）
Java的虚拟机栈存储内容如下：
- 栈帧
    - 局部变量表
    - 操作数栈
    - 动态链接
    - 方法出口
    - 在线程中每一个方法从调用到执行完毕意味着栈帧的入栈和出栈
由于Java的虚拟机栈除了压入和弹出栈帧外不会被直接操作，因此栈帧可以被分配在堆中，Java虚拟机栈的内存可以不连续（JVM规范如此，但是hotspot等虚拟机的虚拟机栈内存都是连续的）

JVM规范允许Java虚拟机栈具有固定的大小，或根据计算需要动态扩展和收缩。
如果Java虚拟机栈时固定大小，那么每个栈的大小可以在创建该栈式单独决定，可以通过参数动态控制Java虚拟机栈的大小
- `-Xss`
    - 可容纳的栈帧数量（栈越大，可以放更多帧）
    - 递归深度
    - 线程创建数量（栈越大，可创建的线程数越少）
    - 通常一个虚拟机栈的大小设置为1M

下面是两个Java虚拟机栈中出现的Error（被设计为Error的原因，Error属于严重错误，Exception属于语言层面的异常）
- 当线程使用的空间超出了规定的Java虚拟机栈的大小会抛出StackOverflowError
    - 栈帧过大（比如定义过大的局部数组）
    - 方法递归太深
- 如果Java虚拟机栈是可以动态扩容的，当JVM给线程的Java虚拟机栈扩容但是内存不足，或者新线程的栈无法获得足够内存抛出OutOfMemoryError
#### hsdb查看Java虚拟机栈
```java
static void foo1() {  
    int x2 = 0xcafebebb;  
    foo2();  
}  
static void foo2() {  
    int x3 = 0xcafebebc;  
    return;//此处打断点暂停  
}  
public static void main(String[] args) {  
    int x0 = 0xcafebeba;  
    foo1();  
}
```
